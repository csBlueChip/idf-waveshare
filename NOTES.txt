3. HARDWARE FACTS (checked)
---------------------------

  Board: Waveshare ESP32-S3-LCD-1.47B, ESP32-S3R8 (8 MB PSRAM), 16 MB flash.
  LCD ST7789 172x320, SPI: MOSI 45, SCLK 40, CS 42, DC 41, RST 39, BL 46.
  RGB LED: GPIO38.   SD (4-bit SDMMC): CLK 14, CMD 15, D0 16, D1 18,
  D2 17, D3 21.   I2C: SDA 48, SCL 47.
  IMU QMI8658A at 0x6B: INT1 = GPIO13, INT2 = GPIO12 (from the schematic).
  IMU orientation table (imu.c s_orientMap) checked on the board:
    ROT 0 = -Y up, ROT 1 = -X up, ROT 2 = +Y up, ROT 3 = +X up.
  Battery: divider /3 (fixed in bat.c).
  UART0 (console / UART UI): TX GPIO43, RX GPIO44.
  USB-C: the chip's USB-Serial/JTAG (FILES switches it to TinyUSB MSC).
  BOOT button: GPIO0 = BTN 1 (must stay so; see open items).
  FreeRTOS tick: 200 Hz (CONFIG_FREERTOS_HZ=200).

  IMU findings (board, with IMU DEBUG):
    - Tap engine reports nothing (STATUS1 no 0x02, TAP_STATUS stays 0x80)
      while any other engine is on (CTRL8 C7 / D1). -> TAP exclusive with
      MOTION/STILL/SIGMO/STEP (ERR on enable). MOTION+STILL+SIGMO work together.
    - Pedometer never counts (no STATUS1 0x10 at 56/224 Hz, step.min 1 or
      10; config matches datasheet Table 38). -> IMU_STEP_ENABLE 0 in imu.c:
      IMU STEP = "not implemented"; code kept; NV step.* kept (unused).
    - Chip SIGMO timing is right (4000 -> 3.98 s with continuous motion)
      but its window runs from the first any-motion and quiet does not
      restart it: move 1 s / rest 4 s / move fired at once. -> SIGMO timed
      in firmware from the motion session start (IMU_SIGMO_CHIP 0; chip
      code kept), max 60000. test_sleep section H checks it.
    - IMU DEBUG lines: "IMU <ms> ST1=.. TAP=..", "IMU <ms> CTRL8=..",
      "IMU <ms> <<IMU ...>>" (copy of each event).

  Checked on the board (done): test_stepb1 (all), test_sleep (all), tap fix,
