WAVEDEMO SCRIPT - QUICK REFERENCE        (full rules: scripting.txt)
====================================

FILES     SD:/scripts/name.s     name: letters digits _ (max 31)   sys/x = system
CONSOLE   RUN [name args]  STOP [NOW]  PAUSE  CONT  LOAD name [args]
          STEP [IN|OUT]  BPT [[file:]n | DEL ALL|#n|[file:]n]  VARS
          LIST [name [from [to]]]  STACK  LOG [UART|USB|BOTH|AUTO]
          EVENTS [src 0|1]
LINES     ; separates   # comment   \; \# \$ literal   "..." '...' quoted
WORDS     split on  space tab : | \n \r      $v[n] (1..$v[0])  $v[0] count

VARIABLES $x local   $$x global   $$scr.bl NV (read-only)   $.x built-in
          ${x}  $${g}  $.{w}  ${x/base,min,dec}  (default /10,0,3)
          VARS $a $$b      (top of a body; only these names allowed)
          $arg  $arg[n]    arguments
BUILT-INS $.ax .ay .az .gx .gy .gz .temp .bat .steps .orient .rnd .ok .err
          .ret .event .time .uptime .runtime .w .h .rot .fw .dropped

ASSIGN    LET $v = expr          LET $v = CALL f args     LET $v = $v $x
          LET $v += -= *= /= expr   $v++  $v--
          LET $v[n] = word       DEL $v[n]                INS $v[n] = word
          GET $v = command       ACC $x $y $z             GYR $x $y $z

EXPR      ( )  ! - ~  * / %  + -  << >>  &  ^  |
          < <= > >= == != ~=  AND OR (lazy)        $a $b = join
FUNCTIONS INT ROUND ABS MIN MAX SQRT SIN COS ATAN2 (degrees) LEN UPPER
          LOWER MID(t,s,n) FIND(t,p) RND(a,b)

OUTPUT    ECHO n text  PRINT text  DEBUG text  APPEND file text
          LOGCAT [file [>DEBUG]]
          QUIET 0|1|2|3 (def 2)  TRACE 0|1           escapes \n \\ \# \$ \1..\9

CONTROL   IF e / ELIF e / ELSE / END
          LOOP $v = a TO b [STEP n] / END      LOOP WHILE e / END
          LOOP n TIMES / END                   LOOP FOREVER / END
          BREAK [n]   NEXT [n|$v]   GOTO label   :label   EXIT
          SWITCH [~]e / v) / a|b) / 1..5) / *) / END   (no fall-through)

FUNCTIONS FN name [$a ...] / RETURN [e] / END
          CALL name args    CALL file.name args    INSERT file.s
SETTINGS  .STACK n    .CONST NAME value...      (top of script)

EVENTS    ON BTN|IMU|UI|TIMER fn    ON src OFF    WAIT EVENT [ms]
          WAIT ms   INPUT $v [ms]   TIMER n ms (n 1..4, 0 = off)
          BTN n SHORT|DOUBLE|DOWN|UP|REPEAT   IMU TAP|2TAP|3TAP|MOTION|STILL|
          SIGMO|STEP n (n/a)|ORIENT 0..3|FLAT|WAKE   UI CONNECT|DISCONNECT|LINK UP|
          LINK DOWN   TIMER n [cnt]
ERRORS    ONERROR STOP|CONT|GOTO label
RANDOM    RNG TRNG | RNG PRNG [seed]
DEBUG     BPT!  (in a script)

SYSTEM    NV sys.autorun 1:  SD:/sys/ onBoot.s onWait.s onConnect.s
          (by hand: RUN sys/onBoot)
          (FN before / instead / after)    hold BOOT 3 s = autorun off
          start-up LED: sys.aron (autorun 1) / sys.aroff (0)
